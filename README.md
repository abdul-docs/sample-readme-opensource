> Zero-dependency, 3.2kb form validation library. Simple, fast, and developer-friendly.

### ⚡ Why QuickForm?
- 📦 **Tiny:** Only 3.2kb gzipped
- 🚀 **Fast:** No dependencies, pure JS
- 🎯 **Simple:** One line to validate
- 💪 **Powerful:** 20+ built-in validators
- 📱 **Works everywhere:** React, Vue, Vanilla JS

### 📥 Installation

```bash
npm install quickform
# or
yarn add quickform
